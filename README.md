# 明星總動員歡樂派對（5～8 歲・明星小鎮）

給岳岳（8 歲）和愷愷（5 歲）的 iPad 網頁遊戲：在遊戲中學習生活知識、養成好習慣。
純靜態網頁，部署在 GitHub Pages，進度存在裝置的 localStorage。
世界觀是「明星小鎮」：一座可以轉的玩具小鎮模型，從家裡延伸到學堂、農場、公園等戶外各個生活空間，每個地方有一位玩具明星。
參考 [toon-fun-party](https://github.com/fantasy1164/toon-fun-party)（2～5 歲版）的設計邏輯，但美術、引擎、角色、關卡都重新設計。

## 安裝到 iPad

1. 用 Safari 開啟 GitHub Pages 網址（https://fantasy1164.github.io/star-party-kids/）。
2. 分享 → 加入主畫面（名稱是「明星小鎮」，跟舊的「歡樂派對」分得開）。
3. 從主畫面的圖示開啟，就是全螢幕。請橫放使用。

用一般瀏覽器打開時，會先出現「把明星小鎮加到主畫面」的引導（`js/ui/install.js`）：會自動判斷 iPad／iPhone Safari（含 Safari 26 的「⋯ → 分享」與「以網頁 App 打開」）、LINE／FB 等 App 內瀏覽器（請改用 Safari 開）、Android Chrome／Samsung、電腦版，並用跳動的箭頭指出按鈕位置。已經從主畫面打開就不會出現；按「這次先在瀏覽器玩」可略過。網址加 `?guide` 可預覽引導、加 `?noguide` 可跳過。注意：在瀏覽器裡玩的進度不會帶到主畫面的 App。

## 手勢（11/24）

轉向、放大的按鈕都拿掉了，全部用手指：

| 手勢 | 作用 |
|---|---|
| 一根手指左右滑 | 轉一圈看（放開會順勢再滑一小段） |
| 一根手指上下滑 | 抬頭、低頭 |
| 兩根手指張開／捏起來 | 拉近、拉遠 |
| 兩根手指一起滑 | 移動畫面 |
| 點一下 | 選東西 |

每天第一次打開（禮物盒打開、大家歡迎完以後），跟閃閃照指引手練習這四個，做到一個打勾一個；右上角可以跳過，40 秒沒做到也會自動跳過。
家長頁「總覽」可以關掉；「進階」可以讓下次打開再練一次。遊戲中需要「轉一轉」時（找東西有躲起來的），會出現左右滑的指引手。程式在 `js/ui/gestures.js`。

## 開場與名人堂（11/24）

- 開場：禮物盒是空心的（四面牆有厚度，打開蓋子看得到裡面在發光）。蓋子彈開後，閃閃站到正前方，其他 17 位明星一個接一個跳出來圍成一圈；
  閃閃喊標題 → 隨機 3 位用自己的聲音歡迎 → 6 位一起喊「歡迎岳岳、愷愷！」（`chorus()`，同時播、錯開一點、音量壓低）→ 選人。打完招呼後點明星會再說一次。
- 名人堂（城市、河邊，地點列最後一個）：18 位明星站在展示台上（後排高、前排矮，閃閃在前排正中間）。點認識的明星 → 用自己的聲音自我介紹加一句英文；
  還沒認識的是灰色剪影，點了閃閃提示去哪裡找。去過那個地方就算認識（`state.met`，跨裝置同步會合併），上方一排小星星顯示認識了幾位，全部認識有一次慶祝。
  角色清單在 `js/data/cast.js`。

## 跨裝置同步進度

進度存在家長自己的 Google 雲端硬碟（`明星總動員存檔／spk.json`），透過家長部署的 Google Apps Script，小孩的裝置不用登入。
跟歡樂派對共用同一個部署（同網址、同家庭密碼，檔案分開）。部署步驟見 [tools/sync/README.md](tools/sync/README.md)；
每台裝置在家長頁「☁️ 雲端同步」輸入一次網址和家庭密碼。打開遊戲自動載入最新進度，有新進度約 45 秒後上傳、離開 app 時馬上上傳；
離線各自玩過會合併（星星、關卡取多的，乘法每題取最近一次作答，貼紙取多的那一邊）。程式在 `js/core/sync.js`。

## 省電（iPhone／iPad 不發燙）

- **大場景用 WebGL**（`js/engine/glscene.js`）：城市、郊區／海邊／山上、世界地圖、透天娃娃屋裡不會動的東西（房子、樹、路燈、道路、遠景）畫在一張畫布上，一次交給 GPU，畫面不動就不重畫。原本城市有 375 張 CSS 3D 圖層，現在只剩十幾張（閃閃、叭叭、地點標記、坐車時的車和行人仍是 CSS，才能動、能說話）。鏡頭矩陣照 CSS 的 transform 算，兩層對得剛好；點擊用射線找畫布上的東西。地面的 CSS 漸層由 `js/engine/csspaint.js` 畫成貼圖。iOS 收回 WebGL 時會自動重建。
- 建場景時：不會動的東西照常 `addBox`／`addSprite`…，建完呼叫 `dio.seal()`；之後加的都是 CSS。建造時就要能動的看板加 `live: true`。小房間仍用 CSS（圖層少，本來就順）。

- 5 秒沒人碰、角色也沒在說話，就把一直重複的小動畫（標記飄動、眨眼、晃動、警車燈）暫停；一碰畫面馬上繼續。畫面完全不動時裝置不用一直重畫。
- 發光效果是固定的，動的只有位置或大小（濾鏡做成動畫每一格都要重畫）。白天看不到的星星不閃。
- 大面積的平面（外圈地面、城市與世界地圖、遠景）縮小畫再放大；轉地圖時角色每 10 度才重新面向鏡頭。

## 設計原則

- **岳岳（ADHD）**：一關 1～2 分鐘、一個畫面一個目標（其他東西變暗）；點下去馬上有聲音和動畫；做完馬上得星星；做錯不扣分，只是彈回去、角色溫柔提醒，錯兩次就把答案亮起來；停 8 秒沒動作出現手指提示；上方的流程條讓他看得到今天還有幾件事；時間到不會中途打斷，先預告「再玩一個就休息」。
- **愷愷（觀察、空間）**：整個遊戲是可以轉的立體模型屋，玩具會躲在家具後面，要轉房間才找得到；照影子形狀把玩具放回架子。
- **一起玩**：一支「明星麥克風」在左下（岳岳）右下（愷愷）之間飛來飛去，拿到麥克風的人才點；等待的人頭上有拍手鈕當啦啦隊（等待也有事做）；一人一份道具（換衣服各自一盤衣服）；輪到誰用誰的難度；不比快慢，完成時兩個人都得星星。
- **少文字**：小孩看到的畫面沒有字（只有開場標題），全部聽角色說。

## 目前內容（第一版）

- 開場：桌上發光的玩具箱，點一下蓋子彈開、閃閃跳出來、玩具飛出來、標題一個字一個字跳出來 → 選人（岳岳、愷愷、一起玩）。第一次長版，之後短版。
- 操作：手指拖到哪，場景就轉到哪（不自動對齊角度，放手會順勢滑一小段）；上下拖可以稍微抬頭低頭；地圖右邊有「拉遠／拉近」按鈕，也可以兩指捏合縮放、兩指拖曳移動。
- 世界沒有「板子的邊」：戶外場景的地面一路延伸、淡進遠方，四周有遠山、樹、樓房、海平線（轉到哪都看得到），不再像浮在空中的一塊桌遊板。
- 地圖分兩層（11/24）：
  - 世界地圖：一座自然的島，海岸線彎彎曲曲、四周是一直延伸到天邊的海；四個區域——城市（生活區，開車就到得了）、郊區（農場）、海邊（海生館、沙灘）、山上（動物園＋纜車）。每張區域地圖右上角有地球鈕回世界地圖。
  - 跨區域可以選「開車走高速公路」（先繫安全帶）或「坐火車」（刷卡進站 → 站在黃線後面 → 先下後上）。路上看窗外找東西（牛、風車、帆船、燈塔、猴子、纜車…），找到會說英文。
  - 城市（明星小鎮）：比畫面大很多，彎彎的馬路、一條河和三座橋，分成住宅區（家、垃圾車路口、學堂、公園）、市中心（超市、圖書館、郵局、捷運站、火車站）、公共設施區（消防局、警察局、醫院），中間穿插一般的透天、公寓、店面、行道樹。鏡頭從現在的位置開始；畫面正上方的地點列點一下，鏡頭飛過去，同一個再點一次就出發。每棟建築形狀都不一樣（學堂有鐘塔、超市有條紋遮雨棚、醫院照大雅清泉醫院的樣子（內縮的方形地基、45 度招牌、急診門口的雨遮）、消防局有車庫和瞭望塔、圖書館有柱子、郵局門口一紅一綠郵筒、火車站有大時鐘），看輪廓就認得。點地方 → 選交通工具（叭叭、公車、警車、消防車；一個人玩還可以騎腳踏車，要先戴安全帽）。
  - 垃圾車：傍晚 16:00～21:00 垃圾車和資源回收車會停在小區路口，進城市時會放〈給愛麗絲〉提醒一次；其他時間也可以去練習。
- 愷愷的貼紙：每做完一關拿一張（恐龍、車車、小動物、哨哨…），在小鎮右上角的貼紙本選一張、點小鎮地面就貼上去，點貼好的可以拿回來。
- 岳岳的畫畫板（小鎮右上角）：彩色筆、黏土筆（鼓鼓的）、橡皮擦、太空印章（火箭、星星，每學會一排口訣多一顆星球），太空或白紙背景；清掉要點兩次。
- 坐叭叭的車：每次都從現在的位置出發。先把安全帶的扣環拖進扣座（一起玩時兩個人各扣一條）。這次遊戲第一次坐車是完整版（約 45 秒）：
  - 遇到紅燈、有人過斑馬線要按大大的停車鈕，綠燈了自己會走；太晚按不扣分，叭叭說「下次早一點」。
  - 路口會浮出箭頭，點往目的地的方向（愷愷版正確的箭頭會發亮）。選方向時鏡頭拉遠、紅旗子浮在屋頂上，小鎮可以轉，從哪個角度看都能找到目的地（不用靠記憶）；一直沒選或選錯兩次，叭叭會提醒轉一轉。
  - 一起玩時愷愷看路（點箭頭）、岳岳踩煞車（按停車鈕）。
  - 之後再坐車是短版：開過去就到，不用一直重做。
- 家：一棟剖開的透天娃娃屋。一樓車庫（叭叭停在這裡，點它就出門）、二樓客廳＋廚房、三樓臥室＋廁所；Z 字型樓梯從一樓貫穿到三樓，扶手在欄杆側，Z 字中間掛著童軍繩編的防墜網。轉到哪個角度，靠近鏡頭的牆都會消失。客廳和廚房有看得到街景的窗戶、通往樓梯的門。今天某個房間三件事都做完，房間上的標記會變綠。
- 每個房間都是「可以轉的立體模型＋上方流程條＋三個漂浮的關卡標記」，每關 1～2 分鐘，做完星星飛進罐子。
- 臥室（晚晚）三個關卡：
  - 收玩具：把玩具拖回架子上一樣形狀的影子。小汽車躲在衣櫃後面（岳岳在的時候火箭也躲在玩具箱後面），要轉房間才看得到；拿起玩具時房間會自動轉回看得到架子的角度。
  - 換衣服：白天選外出服、晚上（17 點後）選睡衣；拿錯季節的衣服會彈回去並說明。岳岳要照順序穿（上衣 → 褲子 → 襪子；睡衣 → 睡褲 → 睡帽），下一件會在流程表上發亮。
  - 晚晚說：聽到「晚晚說」才可以點（拍枕頭、拉窗簾、摸晚晚、拍手）；閃閃會偷偷下口令騙人。岳岳版連晚晚自己沒說「晚晚說」也不算。最後一個口令看時間：晚上關燈、早上打開窗簾、白天站起來轉一圈拍拍手。
- 廁所（橡皮小鴨呱呱）：
  - 刷牙：大嘴巴特寫，牙齒一區一區亮起來，手指拿牙刷來回刷掉細菌小怪獸（愷愷 4 區、岳岳 6 區）。早上和晚上做完，呱呱會開 2 分鐘刷牙歌陪他們真的刷牙（右下角可以跳過）。
  - 洗手：濕 → 抹肥皂（先關水省水）→ 搓（手指真的在螢幕上搓，搓夠久才算）→ 沖 → 擦，上方是步驟圖；愷愷的下一步會發亮，岳岳要看步驟圖。
  - 找危險：地上有水、肥皂掉在地上、吹風機在洗手台的水旁邊；肥皂躲在浴缸後面，要轉房間找。
- 廚房（小恐龍主廚咚咚）：
  - 我的餐盤：把食物拖進餐盤對的格子（蔬菜、主食、豆魚蛋肉、水果），放錯會說明是哪一類；愷愷版格子裡有提示圖；岳岳版沒有提示，還混了糖果、蛋糕（咚咚說明零食不是正餐）。放滿後咚咚開動。
  - 擺餐具：照桌上的虛線幫爸爸、媽媽、阿嬤擺碗和筷子（岳岳一個人玩時再加湯匙）。
  - 什麼能摸：東西從檯面滑過來，可以吃的點一下放進籃子；熱鍋、刀子、熱水壺不要碰，碰了不扣分，咚咚會說明為什麼。
- 客廳（主持人閃閃）：
  - 時間到，關電視：卡通播一下，鬧鐘一響就按遙控器關電視；門鈴、電話響不能關。
  - 誰按電鈴？：從門上的小洞看是誰。爸爸、媽媽、阿嬤可以開門，進來後站在客廳；不認識的人（叔叔、阿姨、送貨員）不開門，要按「找大人」；按了開門會被閃閃擋下來。
  - 明星舞台：跟閃閃做動作（舉手、跳、轉圈、蹲下，真的站起來做），再跟著拍子打鼓（音符掉到鼓上時打）。
- 學堂（機器人老師嗶嗶）：九九乘法，在小鎮點學堂坐車過去。設計重點是「先懂、再練、看得到進步」，不是死背：
  - 修理機器人：聽題目（「六乘七，等於多少？」）選答案，答對裝回一個零件，再唸一次口訣（「六七四十二」）。**第一次玩是程度檢查（12 題，2～5 每排一題、6～9 每排兩題）**，之後一輪 6 題，大約八成是已經會的（會、新、會、會、新、會；剛答錯下一題一定出會的；最後一題一定是會的）。上方一題一顆星的進度列。
  - 答錯的引導（不讓他連錯三次）：錯一次 → 拿掉一個選項、鼓勵再想；錯兩次 → 嗶嗶示範，答案發亮跟著點，再一起唸口訣。六以上的示範用「五的口訣再加上去」（點點前五條藍色、唸五的口訣，再一條一條加）；每天第一次練六以上的排，先教一次這個方法。
  - 具體地誇：上次錯這次對（「你記住了」）、連續答對、自己改對、沒有放棄；有錯過的那一輪最後再誇一次「一直試」。
  - 學會一整排 → 火箭發射到一顆新星球（乘法星空上方有一排星球）。
  - 積木排排站：a×b 照課本的意思是「b 個 a」，點一下放上一整排積木；問一共幾個，答完一排一排亮起來跟著數（6、12、18…），再把房間轉 90 度變成 a 個 b，積木一樣多（交換律）。右上角的眼睛可以從高處往下看。一起玩時愷愷放積木、岳岳回答。
  - 跳跳口訣：閃閃踩石頭跳，嗶嗶數倍數 → 換小孩點亮石頭 → 閃閃停在三格，選這格是多少。岳岳練「正在練的那一排」，愷愷練 2 或 5 的跳數。
  - 口訣唱唱：照順序唱一整排口訣（岳岳唱正在練的那排，愷愷唱 2 或 5），答對一題木琴多一個音，唱完木琴把整首彈一次，再借他自由彈 15 秒。
  - 乘法星空：西牆上 9×9 的星星，學會一題亮一顆，一整排亮了連成星座；點牆可以打開大星空，點星星聽口訣。
  - 家長頁有 8×8 的熟練度表（顏色越綠越熟、✕ 是答錯次數），可以設定下次重新做程度檢查。
- 超市（小豬收銀員多多）：
  - 購物清單：上方是要買的東西，在立體超市裡找；有的躲在貨架後面，要轉房間。岳岳一個人玩時多一樣（麥片）。
  - 付錢：把硬幣拖到托盤湊出價錢（愷愷 3～15 元、用 10／5／1 元；岳岳 17～75 元、多了 50 元）；放太多會說「太多了，拿回來一個」。
  - 裝袋子：冰的（冰淇淋、牛奶、肉、優格）放保冷袋，其他放一般袋子。
- 公園（小鳥啾啾）：
  - 垃圾分類：一般垃圾（灰）、資源回收（藍）、廚餘（綠）。
  - 找小動物：蝴蝶、瓢蟲、青蛙，松鼠躲在樹後面要轉；岳岳版多一個鳥巢（「不要去吵牠」）。
  - 溜滑梯排隊：綠燈時點排第一個的人去溜，紅燈要等；插隊或還在紅燈點會被提醒。
- 醫院・小兒科（謝醫生；泰迪熊護理師抱抱當小幫手）：
  - 看醫生流程：健保卡掛號 → 量身高體重（抱抱）→ 耳溫槍 → 聽心跳 → 看喉嚨 → 貼貼紙。
  - 哪裡不舒服：謝醫生說症狀（肚子痛、發燒頭燙、耳朵痛、鼻子過敏、膝蓋破皮…；岳岳版有喉嚨、眼睛癢、手肘、腳扭到），點身上那個地方，學會把哪裡不舒服告訴大人。
  - 勇敢打針：先深呼吸三次（按住按鈕吸氣、氣球變大，放開吐氣、氣球變小，按不到兩秒會提醒慢慢吸），酒精棉擦一擦、數一二三，貼 OK 繃，抱抱給一個抱抱。
  - 視力檢查：E 的開口朝哪邊就往那邊滑（或點那邊的箭頭），E 越來越小；愷愷錯一次、岳岳錯兩次，對的箭頭會發亮。
  - 生病怎麼快點好：多喝水、睡覺、吃蔬菜、照醫生吃藥放愛心；冰飲料、吃冰、糖果、晚上玩手機放叉叉。做完謝醫生會說他的口頭禪。
  - 謝醫生的口頭禪「過敏平常就要保養，少喝冰的、吃甜的，才會比較快好」：點謝醫生、鼻子過敏那題、生病分類做完都會說。
- 農場（木頭小馬達達）：
  - 餵動物：紅蘿蔔給兔子、牧草給牛、玉米給雞。
  - 撿雞蛋：雞蛋藏在稻草、雞舍後面，要轉農場找。
  - 種菜：挖洞 → 放種子 → 蓋土 → 澆水 → 曬太陽，菜長出來。
- 一起玩時，每個關卡都輪流：拿麥克風的人做一步，等待的人可以當啦啦隊拍手。
- 思考時間：要動腦的題目出來時，背景音樂淡到幾乎聽不到、不放裝飾音效；一起玩時等待的人按拍手只亮光，答完才出聲（岳岳對聲音很敏感）。家長頁可以開「安靜模式」（關掉背景音樂和裝飾音效）。
- 廚房多一關「分水餃」：b 盤、每盤 a 顆就是 a×b；愷愷照第一盤放水餃，岳岳回答一共幾顆（答錯一盤一盤數）。
- 公園多一關「挖恐龍化石」：手指撥開沙子找三塊化石，看形狀和方向放回骨架，恐龍活過來；找動物多了鴨子、烏龜。農場有小豬、綿羊可以點。
- 警察局（玩具警察狗哨哨，原創角色）：指揮交通（有人過馬路舉停、走完才舉走，太早會被提醒等一下）、過馬路步驟（停在路邊 → 看左 → 看右 → 再看左 → 等綠燈 → 走斑馬線）、走散了找誰幫忙（警察、店員、帶小孩的媽媽可以；給糖果叫你跟他走、叫你上車的陌生人不可以）。
- 客廳舞台跳完、打完鼓，再給 12 秒自己編節奏（三顆鼓）。
- 城市新地點（11/24）：
  - 消防局（玩具消防栓嘩嘩）：打 119、火災逃生步驟（濕毛巾摀口鼻 → 低姿勢 → 走樓梯不搭電梯 → 到外面集合 → 打 119）、開消防車噴水滅火。
  - 捷運站（玩具捷運咻咻）：刷卡進站、站黃線後面、先下後上；博愛座讓給誰；看路線圖一站一站坐（岳岳再數坐了幾站）。
  - 圖書館（貓頭鷹咕咕）：哪裡要小聲；聽故事回答問題（三個原創小故事）；把書放回書架（愷愷看顏色、岳岳看書背上的 A／B／C）。

  - 垃圾車停靠點（閃閃）：倒垃圾步驟、垃圾袋丟垃圾車／果皮倒廚餘桶、資源回收分類（紙類、寶特瓶、鐵鋁罐；岳岳多一格「不能回收的丟一般垃圾」）。
- 海邊（參考屏東海生館）：海生館（玩具白鯨白白：海底隧道找海洋動物、企鵝依高矮排隊、參觀規則）、沙灘（小螃蟹夾夾：防曬步驟、撿貝殼分類、海邊安全）。
- 山上（參考木柵動物園）：動物園（玩具熊貓竹竹：在動物園找熊貓、長頸鹿、企鵝、無尾熊、斑馬、獅子、台灣黑熊、石虎；誰吃什麼；動物園規則）。
- 學堂多一關 ABC：嗶嗶唸「A，A for apple，蘋果。哪一個是 A？」，點對的字母；一輪 5 題（新字母 1～2 個，其他複習），最後木琴彈字母歌旋律、學過的字母一個一個亮。

## 開發

沒有打包步驟，改完直接 commit、push 就會自動部署。

    python -m http.server 8000     # 本機預覽 http://localhost:8000

測試用網址參數：`?hour=20.5`（假裝幾點）、`?date=2026-12-24`、`?notts=1`（不出聲、快速略過台詞）、`?debug=1`（顯示語音事件）。
`engine-test.html?spin=1` 是立體引擎效能測試（自動繞圈、左上角顯示 FPS）。

### 立體模型屋引擎

- 地板 x（東）× y（南），z 往上；鏡頭預設在東南方。`createDiorama()` 之後用 `addBox`（方塊家具，每一面依房間裡固定的光上色）、`addSprite`（一直面向鏡頭的看板：角色、玩具）、`addDecal`（地毯、影子）、`wallArt`（窗戶、海報）。
- 牆只畫朝內的一面，鏡頭轉到牆外面時那面牆自動不畫（只留矮牆根），所以前面的牆永遠不會擋住。
- 手指左右滑轉房間，放開後停在最近的斜角；`rotateBy(±90)`、`faceQuadrant(q)`、`animateTo({ a, z, px, py })` 控制鏡頭。

## 產生角色語音

角色的聲音與說話風格在 `tools/voice-config.json`，台詞在 `js/data/lines.js`（九九乘法的題目、口訣、數字由檔案最後的程式產生，口訣照學校唸法：二三得六、三四十二、二五一十）。用法跟 toon-fun-party 一樣：

    $env:GEMINI_API_KEY = "你的金鑰"     # PowerShell；金鑰不要寫進任何檔案
    node tools/gen-voice.mjs --dry        # 先看會產生哪些
    node tools/gen-voice.mjs --line title # 先做一句試聽
    node tools/gen-voice.mjs              # 產生全部
    node tools/check-lines.mjs            # 檢查台詞代號有沒有重複

台詞改過字（例如名字從凱凱改成愷愷）的句子會自動重做：`assets/voice/texts.json` 記著每個語音檔當初唸的是哪句話。

沒有語音檔的句子，遊戲會先用裝置內建語音（依角色調音高與語速）。

新增 js 檔案時，記得加進 `sw.js` 的 `CORE` 清單，並把 `CACHE` 版本號加一。
