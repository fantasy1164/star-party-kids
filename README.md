# 明星總動員歡樂派對（5～8 歲・玩具屋）

給岳岳（8 歲）和凱凱（5 歲）的 iPad 網頁遊戲：在遊戲中學習生活知識、養成好習慣。
純靜態網頁，部署在 GitHub Pages，進度存在裝置的 localStorage。
參考 [toon-fun-party](https://github.com/fantasy1164/toon-fun-party)（2～5 歲版）的設計邏輯，但美術、引擎、角色、關卡都重新設計。

## 安裝到 iPad

1. 用 Safari 開啟 GitHub Pages 網址（https://fantasy1164.github.io/star-party-kids/）。
2. 分享 → 加入主畫面（名稱是「玩具屋派對」，跟舊的「歡樂派對」分得開）。
3. 從主畫面的圖示開啟，就是全螢幕。請橫放使用。

## 設計原則

- **岳岳（ADHD）**：一關 1～2 分鐘、一個畫面一個目標（其他東西變暗）；點下去馬上有聲音和動畫；做完馬上得星星；做錯不扣分，只是彈回去、角色溫柔提醒，錯兩次就把答案亮起來；停 8 秒沒動作出現手指提示；上方的流程條讓他看得到今天還有幾件事；時間到不會中途打斷，先預告「再玩一個就休息」。
- **凱凱（觀察、空間）**：整個遊戲是可以轉的立體模型屋，玩具會躲在家具後面，要轉房間才找得到；照影子形狀把玩具放回架子。
- **一起玩**：一支「明星麥克風」在左下（岳岳）右下（凱凱）之間飛來飛去，拿到麥克風的人才點；等待的人頭上有拍手鈕當啦啦隊（等待也有事做）；一人一份道具（換衣服各自一盤衣服）；輪到誰用誰的難度；不比快慢，完成時兩個人都得星星。
- **少文字**：小孩看到的畫面沒有字（只有開場標題），全部聽角色說。

## 目前內容（第一版）

- 開場：桌上發光的玩具箱，點一下蓋子彈開、閃閃跳出來、玩具飛出來、標題一個字一個字跳出來 → 選人（岳岳、凱凱、一起玩）。第一次長版，之後短版。
- 玩具屋（家）：四個房間的立體模型，可以轉。臥室開放；廁所、廚房放三角錐（準備中）。
- 臥室（晚晚）三個關卡：
  - 收玩具：把玩具拖回架子上一樣形狀的影子。小汽車躲在衣櫃後面（岳岳在的時候火箭也躲在玩具箱後面），要轉房間才看得到；拿起玩具時房間會自動轉回看得到架子的角度。
  - 換衣服：白天選外出服、晚上（17 點後）選睡衣；拿錯季節的衣服會彈回去並說明。岳岳要照順序穿（上衣 → 褲子 → 襪子；睡衣 → 睡褲 → 睡帽），下一件會在流程表上發亮。
  - 晚晚說：聽到「晚晚說」才可以點（拍枕頭、拉窗簾、摸晚晚、拍手）；閃閃會偷偷下口令騙人。岳岳版連晚晚自己沒說「晚晚說」也不算。最後一個口令看時間：晚上關燈（房間變暗、星星貼紙亮起來）、早上打開窗簾讓太陽進來、白天站起來轉一圈拍拍手。
  - 三個都做完：大家一起慶祝；晚上提醒去真的刷牙睡覺、早上提醒去換衣服出門。
- 沒在玩關卡的時候，點閃閃、晚晚、枕頭、窗簾也都會有反應。
- 時間：日夜跟現實同步（窗外天空、房間光線、晚晚晚上會發光）；每次 15 分鐘後閃閃的發條轉完要休息（右上角的金色發條時鐘），休息完自動回來；21:00～6:00 是睡覺時間。
- 家長頁：在開場或休息、睡覺畫面，長按左下角的鎖 3 秒。可看這一週的星星與完成紀錄、調遊玩與休息時間、睡覺時間、音樂大小、測試時間。

## 角色（玩具明星）

| 角色 | 是什麼 | 負責 |
|---|---|---|
| 閃閃 | 星星造型的發條玩具，拿著明星麥克風 | 主持人、輪流唱名、會調皮騙人 |
| 晚晚 | 戴睡帽的月亮夜燈娃娃 | 臥室 |

之後的場景：廁所（橡皮小鴨呱呱）、廚房（小恐龍咚咚）、學堂（機器人嗶嗶老師）、汽車（遙控車叭叭）、農場（木頭小馬達達）。

## 開發

沒有打包步驟，改完直接 commit、push 就會自動部署。

    python -m http.server 8000     # 本機預覽 http://localhost:8000

測試用網址參數：`?hour=20.5`（假裝幾點）、`?date=2026-12-24`、`?notts=1`（不出聲、快速略過台詞）、`?debug=1`（顯示語音事件）。
`engine-test.html?spin=1` 是立體引擎效能測試（自動繞圈、左上角顯示 FPS）。

## 結構

    index.html, manifest.webmanifest, sw.js
    css/main.css
    js/main.js              進入點、畫面切換
    js/config.js            小孩、角色、預設設定（代表色暫定）
    js/engine/diorama.js    等角立體模型屋引擎（CSS 3D）
    js/core/                時間、存檔、聲音（玩具樂器合成）、語音、輪流、遊玩時間與手指提示
    js/data/lines.js        台詞表
    js/art/                 SVG 美術（玩具明星、小孩、玩具、衣服、圖示）
    js/ui/                  開場與選人、玩具屋、休息與睡覺、家長頁、共用介面
    js/scenes/              臥室（模型與關卡）
    tools/                  語音產生工具（沿用 toon-fun-party）

存檔與快取都用 `spk-` 開頭（舊遊戲是 `tfp-`），兩個遊戲在同一個網域不會互相覆蓋。

### 立體模型屋引擎

- 地板 x（東）× y（南），z 往上；鏡頭預設在東南方。`createDiorama()` 之後用 `addBox`（方塊家具，每一面依房間裡固定的光上色）、`addSprite`（一直面向鏡頭的看板：角色、玩具）、`addDecal`（地毯、影子）、`wallArt`（窗戶、海報）。
- 牆只畫朝內的一面，鏡頭轉到牆外面時那面牆自動不畫（只留矮牆根），所以前面的牆永遠不會擋住。
- 手指左右滑轉房間，放開後停在最近的斜角；`rotateBy(±90)`、`faceQuadrant(q)`、`animateTo({ a, z, px, py })` 控制鏡頭。

## 產生角色語音

角色的聲音與說話風格在 `tools/voice-config.json`，台詞在 `js/data/lines.js`。用法跟 toon-fun-party 一樣：

    $env:GEMINI_API_KEY = "你的金鑰"     # PowerShell；金鑰不要寫進任何檔案
    node tools/gen-voice.mjs --dry        # 先看會產生哪些
    node tools/gen-voice.mjs --line title # 先做一句試聽
    node tools/gen-voice.mjs              # 產生全部
    node tools/check-lines.mjs            # 檢查台詞代號有沒有重複

沒有語音檔的句子，遊戲會先用裝置內建語音（依角色調音高與語速）。

新增 js 檔案時，記得加進 `sw.js` 的 `CORE` 清單，並把 `CACHE` 版本號加一。
