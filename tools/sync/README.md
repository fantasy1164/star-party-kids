# 雲端存檔（Google Apps Script）

進度存在你自己的 Google 雲端硬碟：`我的雲端硬碟／明星總動員存檔／spk.json`，
每天第一次存檔前會把當天開始時的進度複製到 `舊版本／`（保留 30 天）。小孩的裝置都不用登入 Google，
每台第一次在家長頁「☁️ 雲端同步」輸入網址和「家庭密碼」即可。

這份 `Code.gs` 跟歡樂派對（toon-fun-party）共用：同一個部署、同一組網址和家庭密碼，兩個遊戲的檔案分開
（歡樂派對是 `progress.json`，明星小鎮是 `spk.json`），不會互相蓋掉。

## 已經幫歡樂派對部署過了

1. 打開 <https://script.google.com> 裡的「明星總動員存檔」專案。
2. 把編輯器裡的程式換成本資料夾的 `Code.gs`，**第 13 行的家庭密碼改回你原本的密碼**，按儲存。
3. 「部署」→「管理部署作業」→ 鉛筆 → 版本選「新版本」→「部署」。網址不會變。
4. 在明星小鎮的家長頁「☁️ 雲端同步」貼上同一個網址、輸入同一組家庭密碼。

舊版的歡樂派對不受影響（它不帶 app 參數，照樣讀寫 `progress.json`）。

## 第一次部署（在電腦上做一次，約 5 分鐘）

1. 用要放存檔的 Google 帳號打開 <https://script.google.com>，按「新專案」。
2. 左上角把專案名稱改成「明星總動員存檔」。
3. 把編輯器裡的程式全部刪掉，貼上本資料夾的 `Code.gs`。
4. 把第 13 行的 `請改成你的家庭密碼` 改成你自己的密碼（8 碼以上，英數混合），按儲存。
5. 上方函式選單選 `setup`，按「執行」：
   - 跳出「需要授權」→「審查權限」→ 選你的帳號。
   - 看到「Google 尚未驗證這個應用程式」：這是你自己寫的程式，按「進階」→「前往 明星總動員存檔（不安全）」→「允許」。
   - 執行紀錄出現「資料夾已就緒」，雲端硬碟裡就會多一個「明星總動員存檔」資料夾。
6. 右上角「部署」→「新增部署作業」→ 齒輪選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按「部署」，複製「網頁應用程式」網址（結尾是 `/exec`）。
7. 每台裝置：家長頁「☁️ 雲端同步」貼上網址、輸入家庭密碼，按「儲存並同步」。

## 同步怎麼運作

- 打開遊戲時自動載入雲端最新進度；玩的時候（有新星星、貼紙、乘法紀錄）過一會兒自動上傳；離開 app 時馬上上傳。
- 兩台在沒網路時各自玩過，連上後會合併：每天的星星、玩過的關卡取多的；乘法每一題取最近一次作答的熟練度；貼紙取比較多的那一邊。
- 「用雲端進度覆蓋這台」：這台的進度不要了，直接換成雲端的（例如這台之前拿來測試）。
- 「假裝現在幾點」的測試模式中暫停同步，免得測試資料傳上去。
- 畫畫板的圖只存在各台裝置上（圖片太大，不同步）。

## 安全

- 網址加上家庭密碼才能讀寫；10 分鐘內錯 10 次會暫停 10 分鐘。
- 密碼只在 Apps Script 和各裝置本機，不會寫進 GitHub。
- 想換密碼：改 `FAMILY_PASS` → 部署新版本 → 每台裝置重新輸入。
- 想停用：「部署」→「管理部署作業」→ 封存。
